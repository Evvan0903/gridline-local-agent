# Qwen3.8:27B extended local experiment

Opt-in controller argument `execution_profile='extended_local_60m'` is accepted only for Single Model / General Analyst / exact `qwen3.8:27b`. It selects 3600 seconds, a 600-second maximum local request timeout, and `None` request/tool ceilings. Existing fixed defaults and historical benchmark configurations are unchanged. This option is currently available through Python, not the web UI.

The once-only experiment entry is `python -B -m examples.qwen_extended_eval` using the project virtual environment. It refuses an existing `output/gridline_v3/qwen38_27b_extended_20261018` directory. Do not remove that directory to retry. No automatic retry, fallback, download, cloud SDK invocation or OpenAI connection is allowed. The child removes its API key environment value and permits only loopback Ollama port 11434.

The runner uses main-thread POSIX timers for per-request and total inference deadlines. The independent oracle starts only after inference stops and is outside the inference deadline. Create `CANCEL` in the experiment directory or send SIGINT to interrupt an in-flight request. Cancellation monitoring runs in a temporary thread and stops at exit. Existing user model caches block a conflicting heavyweight run; only a target cache loaded by this experiment may be released at exit. No user service is stopped.

Progress guards stop after three identical failed tool invocations without a new successful action, or six successive invocations whose exact tool/argument signatures were previously seen. Corrected arguments and new tool actions reset the latter counter. These are observable repetition heuristics, not semantic proof of progress. The existing 180k-character context safety bound remains and is reported as an unrecoverable context constraint if reached. No additional numeric request/tool ceiling is introduced. Final synthesis is requested when fewer than 180 seconds remain; an earlier long request may consume that remaining opportunity. Actual completion is determined separately by the original deterministic acceptance checks.

Frozen task/rules/source bytes are copied from the original V3 experiment. A system message overrides only its obsolete eight-request scheduling sentence. No answer totals or reference pipeline are provided to the model. Full history, SQL, spec attempts, artifacts, resources and independent verification remain in the isolated output directory.
